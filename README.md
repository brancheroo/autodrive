# Autodrive

A browser self-driving ride simulator: pick a car, enter any two US addresses, and ride coast to coast on real streets with live maps, traffic, weather, charging stops, and AI Radio.

**Play:** open the GitHub Pages link for this repository (Settings → Pages).

Needs an internet connection (maps and data stream live) and a recent desktop browser.
